## Standing notes for future runs

  this clone only. Anyone else cloning the fork will see run artifacts. Left as-is by decision.
- **Husky + lint-staged are live.** Any commit runs `eslint --fix` and `prettier --write` over
  staged files, so hooks may rewrite what a run wrote.

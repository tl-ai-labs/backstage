# Intent Brief — docs — TSDoc for the 45 undocumented exports of @backstage/catalog-model

## Context

`packages/catalog-model/report.api.md` (the stable `@public` API report) carries 45
`(undocumented)` markers. Undocumented-export warnings are switched off in `build:api-reports`,
so these markers are the only signal. They break down as:

- 8 entity type guards, tag-only `/** @public */` blocks — `src/entity/conditions.ts`:
  `isApiEntity`, `isComponentEntity`, `isDomainEntity`, `isGroupEntity`, `isLocationEntity`,
  `isResourceEntity`, `isSystemEntity`, `isUserEntity`.
- 24 entity-kind members — `apiVersion`, `kind`, `spec` on `ApiEntity`, `ComponentEntity`,
  `DomainEntity`, `GroupEntity`, `LocationEntity`, `ResourceEntity`, `SystemEntity`, `UserEntity`
  (`src/kinds/*EntityV1alpha1.ts`).
- 5 `enforce` methods — `DefaultNamespaceEntityPolicy`, `FieldFormatEntityPolicy`,
  `GroupDefaultParentEntityPolicy`, `NoForeignRootFieldsEntityPolicy`, `SchemaValidEntityPolicy`
  (`src/entity/policies/`).
- 8 static methods of `KubernetesValidatorFunctions` (`src/validation/KubernetesValidatorFunctions.ts`):
  `isValidApiVersion`, `isValidKind`, `isValidObjectName`, `isValidNamespace`, `isValidLabelKey`,
  `isValidLabelValue`, `isValidAnnotationKey`, `isValidAnnotationValue`.

## Goal

Every one of the 45 markers gets an accurate TSDoc description that states what the code
actually does (verified against its implementation), so `report.api.md` shows no
`(undocumented)` marker after `yarn build:api-reports`.

Audience: Backstage adopters and plugin authors reading the API reference. Style: edit the
existing `/** @public */` blocks in place, matching the package's TSDoc style
(`.sdlc/baseline/stack-profile.md`); keep the release tags.

- Project defaults (`.env*`, `.mcp.json`, `node_modules/**`, `.cursor/rules/**`,

- Detected AI configs: `.claude/`, `.claude/CLAUDE.md`, `.claude/settings.local.json`,
  `.claude/skills/`, `.cursor/rules/`, `.github/copilot-instructions.md`, `AGENTS.md`
- `docs/releases/**`, ESLint / Prettier / TypeScript configs, `.gitignore`
- Every other file under `packages/catalog-model/` and the rest of the monorepo

## Acceptance criteria

- Run test command (use exactly, word for word, for the whole run):
  `yarn build:api-reports && ! grep -q "(undocumented)" packages/catalog-model/report.api.md`
  — it must exit 0.
- Every new description is accurate against its implementation (e.g. the type guards compare
  `kind` case-insensitively; `enforce` behaviour per policy).
- Only comments change: no code, signatures, or release tags change; no copyright years change.
- Changed files are prettier-formatted (`yarn prettier --write <changed paths>`).
- Never run lint with `--fix`.
- Do not read open upstream PRs; proceed regardless of them.
- Auth mode: `vendor`. Policy endpoints (Vertex AI in project `temp-genmedia-study`, and
  Anthropic) are confirmed acceptable. `.gitignore` is not edited.
- The changeset names only `@backstage/catalog-model`, `patch`, written for adopters.

## Non-goals

- The 25 markers in `report-alpha.api.md` (some may clear as a side effect, since alpha
  re-exports shared kinds).
- Nested fields under `spec` (e.g. `ComponentEntity.spec.owner`) — the API report does not
  mark them.
- README or `/docs` changes.

## Gate 0 — approved 2026-11-04

- Scope frozen as listed above (18 allowlist paths, 18 off-limits patterns).
- Auth mode `vendor`; policy `argon4-plus-sonnet55`.
- Test command (verbatim): `yarn build:api-reports && ! grep -q "(undocumented)" packages/catalog-model/report.api.md`
- `yarn build:api-reports` regenerates every package's report: after each run, any change to a
  report outside `packages/catalog-model/` is reverted with `git checkout -- <path>` and listed
  in the final report.

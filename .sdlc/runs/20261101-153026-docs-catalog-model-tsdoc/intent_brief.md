# Intent Brief — docs — TSDoc for undocumented @backstage/catalog-model exports

## Context

`@backstage/catalog-model` (1.10.2, public) defines what a catalog entity is (kinds like Component, API,
Group), how references such as `component:default/foo` are parsed and how entities are validated.
`packages/catalog-model/report.api.md` marks 45 declarations `(undocumented)` at base commit
`f20fd9b59828` (`report-alpha.api.md` marks 25 more). The flagged declarations are mostly kind interface
members (`apiVersion`, `kind`, `spec`), the `is*Entity` type guards, entity policy classes and their
constructors, `KubernetesValidatorFunctions` statics, `Validators` members and `CompoundEntityRef` fields.

Audience: plugin authors and other engineers who build against the entity model.

## Goal

Write accurate TSDoc for every declaration `report.api.md` marks `(undocumented)`, updating the package's
source TSDoc in place across kinds, relations, validation and entity helpers, then regenerate the API
reports. Match the TSDoc style the package already uses. Accuracy matters more than volume: describe what
the code does, not what it sounds like it does.

## Files in scope

- `packages/catalog-model/src/**/*.ts` (source files holding the flagged declarations; no `*.test.ts`)
- `packages/catalog-model/report.api.md`, `packages/catalog-model/report-alpha.api.md` (regenerated by
  `yarn build:api-reports` only, never hand-edited)
- `.changeset/catalog-model-tsdoc.md` (new, `patch` for `@backstage/catalog-model`)

Gate 0 approved 2026-11-01: policy `opus55-plus-flash38`, auth `estimated`, test command
`CI=1 yarn test packages/catalog-model`; write contract frozen with the allowlist above. The 45 flagged
declarations with context are listed in `.sdlc/runs/20261101-153026-docs-catalog-model-tsdoc/undocumented-markers.txt`.

## Files off-limits

- Project defaults from setup (`.env*`, `.mcp.json`, `.cursor/rules/**`, `.claude/settings.local.json`,
  `node_modules/**`, `dist/**`, `build/**`, `.next/**`, `.sdlc/**`, `.git/**`)
- AI configs: `.claude/**`, `AGENTS.md`, `.cursor/**`, `.github/copilot-instructions.md`
- `packages/catalog-model/CHANGELOG.md`, `packages/catalog-model/knip-report.md`, `docs/releases/**`
- ESLint, Prettier and TypeScript config files
- Every other package and plugin

## Acceptance criteria

- `yarn build:api-reports` passes.
- `packages/catalog-model/report.api.md` contains zero `(undocumented)` markers.
- No runtime code or type signature changes; `CI=1 yarn test packages/catalog-model` and `yarn tsc` still pass.
- Each new comment is accurate to the implementation it documents.

## Non-goals

- Clearing the `(undocumented)` markers in `report-alpha.api.md` (outside the acceptance check; in scope
  only if they fall in the same edits).
- Rewriting existing TSDoc, documenting internal (non-exported) symbols, or changing `/docs` pages.

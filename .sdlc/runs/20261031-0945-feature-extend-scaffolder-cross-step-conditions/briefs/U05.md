### U01 — edit `plugins/scaffolder-react/src/next/lib/schema.ts` (codegen)

Behaviour: Adds liftCrossStepDependencies, a pure helper that rewrites a step's dependencies keyed on a property the step does not define (an earlier-step answer) into equivalent allOf if/then entries, so rjsf and json-schema-library evaluate them against the whole wizard form data.

Rules:

1. 1. Signature: export const liftCrossStepDependencies = (schema: JsonObject): JsonObject; it never mutates its input or any nested object of it (build new objects with spread).
2. 2. If schema.dependencies is not an object (use the file's isObject guard) or schema.properties is not an object, return the input schema itself (same reference).
3. 3. Walk Object.entries(schema.dependencies) in order. An entry whose key is an own key of schema.properties (Object.prototype.hasOwnProperty.call) stays in the remaining dependencies untouched.
4. 4. For any other key k: an array value D becomes one lifted entry { if: { required: [k] }, then: { required: D } }.
5. 5. For any other key k: an object value without an array oneOf becomes one lifted entry { if: { required: [k] }, then: <the dependency value> }.
6. 6. For any other key k: an object value with an array oneOf becomes, for each oneOf branch that is an object whose properties object has own key k, one entry { if: { properties: { [k]: branch.properties[k] }, required: [k] }, then: <branch copy whose properties omit k> }; branches without k are skipped; if the dependency value has keys other than oneOf, add one more entry { if: { required: [k] }, then: <those other keys> } after the branch entries.
7. 7. Any other value type (boolean, string) for key k stays in the remaining dependencies untouched.
8. 8. If nothing was lifted, return the input schema itself (same reference).
9. 9. Otherwise return { ...schema, allOf: [...existing schema.allOf entries when schema.allOf is an array, ...lifted entries in walk order] } with dependencies set to the remaining entries, and with the dependencies key removed entirely when none remain.
10. 10. Put it after extractSchemaFromStep, with a TSDoc comment explaining that rjsf skips dependencies whose trigger is not one of the step's own properties; give it no release tag and do not add it to lib/index.ts (it stays internal).

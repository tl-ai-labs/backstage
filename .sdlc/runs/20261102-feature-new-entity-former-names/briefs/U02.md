### U02 — create `packages/catalog-model/src/entity/formerNames.ts` (codegen)

Behaviour: Parses the `backstage.io/former-names` annotation of an entity into normalized former refs and a list of rejected entries, and never throws.

Rules:
1. 1. Read `entity.metadata.annotations?.[ANNOTATION_FORMER_NAMES]`. If it is absent or not a string, return `{ formerRefs: [], problems: [] }`.
2. 2. Split the value on `,` and trim each entry. A blank entry adds a problem with reason `it is empty`.
3. 3. Test each other entry against `/^(?:[^\s:/,]+:)?(?:[^\s:/,]+\/)?[^\s:/,]+$/`. On no match add a problem with reason `it is not on the form [<kind>:][<namespace>/]<name>`.
4. 4. Parse with `parseEntityRef(entry, { defaultKind: entity.kind, defaultNamespace: entity.metadata.namespace || DEFAULT_NAMESPACE })` and normalize with `stringifyEntityRef`, which lower-cases.
5. 5. In this order, add a problem and skip the entry: reason `it is longer than 255 characters` when the normalized ref is over 255 characters; reason `its kind is not the kind of this entity` when the parsed kind differs from `entity.kind` compared lower-cased; reason `it is the current name of this entity` when the ref equals `stringifyEntityRef(entity)`.
6. 6. Keep a valid ref once, in declaration order; a repeat is dropped with no problem.
7. 7. Each problem holds the trimmed entry as written and its reason, in declaration order.

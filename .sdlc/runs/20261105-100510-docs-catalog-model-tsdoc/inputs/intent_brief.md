# Intent Brief — docs — TSDoc for the 45 undocumented exports of @backstage/catalog-model

## Context
`@backstage/catalog-model` (v1.10.2, published) defines what a catalog entity is (kinds like Component, API, Group), how references such as `component:default/foo` are parsed, and how entities are validated. 45 of its exports are marked `// (undocumented)` in `packages/catalog-model/report.api.md`. The repo's `build:api-reports` passes `-o ae-undocumented`, so they appear only as those markers, not as warnings.

## Goal
Write accurate TSDoc in place in the package source for all 45 undocumented exports, covering kinds, relations, validation and entity helpers. Then regenerate the API reports. Audience: plugin authors and other engineers who build against the entity model. Match the TSDoc style the package already uses: summary-only member comments with no release tags, `@param value - …`, and `{@inheritDoc}` where it fits. Accuracy matters more than volume: describe what the code does, not what it sounds like it does.

The 45 exports:
- 8 type guards in `src/entity/conditions.ts` (`isApiEntity` … `isUserEntity`). Each already has a `@public`-only block, so the summary goes into it.
- 8 `KubernetesValidatorFunctions` static methods in `src/validation/KubernetesValidatorFunctions.ts`.
- 5 `enforce` methods in `src/entity/policies/` (DefaultNamespace, FieldFormat, GroupDefaultParent, NoForeignRootFields, SchemaValid).
- 24 kind interface members (`apiVersion`, `kind`, `spec`) across the 8 `src/kinds/*EntityV1alpha1.ts` files.

## Files off-limits
- Project defaults (.env*, .mcp.json, node_modules/**, dist/**, .sdlc/**, .git/**, .cursor/rules/**, .claude/settings.local.json)
- AI configs: .claude/**, AGENTS.md, .cursor/**, .github/copilot-instructions.md
- Every other package's report*.api.md, all CHANGELOG.md files, knip-report.md, docs/releases/**
- Any runtime code change in catalog-model. Only comments change.

## Acceptance criteria
- `yarn build:api-reports` passes.
- `packages/catalog-model/report.api.md` contains zero `(undocumented)` markers.
- Every new comment is accurate against the implementation it documents.
- `yarn tsc` passes and `CI=1 yarn test packages/catalog-model` stays green (no behavior change).

## Non-goals
- The 19 alpha-only undocumented items in `report-alpha.api.md`.
- Rewriting existing TSDoc, and any change to `/docs` or the README.
- Code or behavior changes.

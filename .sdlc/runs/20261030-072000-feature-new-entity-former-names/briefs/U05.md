### U02 — create `packages/catalog-model/src/entity/formerEntityRefs.ts` (codegen)

Behaviour: Parses the comma-delimited former-entity-refs annotation value into a normalized, de-duplicated, order-stable list of full entity refs, failing closed per entry and never throwing.

Rules:
1. 1. Export one function, `parseFormerEntityRefs(value: string | undefined)`, returning `string[]`. It MUST NOT throw for any input whatsoever, including undefined, null cast as the parameter type, the empty string, and arbitrary junk.
2. 2. Return `[]` immediately when `value` is not a non-empty string after trimming.
3. 3. Split the value on the ',' character. There is NO escape syntax: a valid entity ref can never contain a comma because parseEntityRef's grammar is [<kind>:][<namespace>/]<name> over DNS-label characters. Do not implement quoting or backslash handling.
4. 4. For each split entry: trim leading and trailing whitespace; skip the entry when the trimmed result is empty.
5. 5. For each surviving entry, call `parseEntityRef(entry)` inside a try/catch with NO default kind and NO default namespace context argument, so an entry that omits the kind is rejected rather than silently defaulted to some unrelated kind. On a thrown error, skip ONLY that entry and continue with the rest — never abandon the whole value.
6. 6. Canonicalize each successfully parsed entry through `stringifyEntityRef`, which is the only lowercasing function in the package, producing a full lowercase `kind:namespace/name` string.
7. 7. De-duplicate the canonicalized refs while preserving first-occurrence order. Use a Set for membership and build the result array in encounter order; do not sort.
8. 8. After de-duplication, if the result length exceeds FORMER_ENTITY_REFS_MAX_COUNT, return `[]` — the whole declaration is refused, not truncated to a prefix, so an over-budget declaration fails visibly rather than leaving some refs silently dead.
9. 9. TSDoc the function with `@public`, a summary, and a `@remarks` block stating explicitly that it never throws, that malformed entries are dropped individually, and that a declaration exceeding the maximum count resolves to nothing.
10. 10. Import parseEntityRef and stringifyEntityRef from './ref' and the two constants from './constants'. Apache 2.0 header with year 2026.

7. 7. It inspects only two kinds of condition: (a) `if` nodes, meaning `schema` itself and each object item of `schema.allOf` whose `if` is an object; the condition reads the own keys of `if.properties` plus the string items of `if.required`, and its branches are `then` and `else` (objects only); (b) each own key `k` of `schema.dependencies` whose value is an object; the condition reads `k`, and its branch is that value. 10. 10. Return `{ keys, fields }`, each in first-seen order without duplicates; a schema with only same-step conditions (or none) returns `{ keys: [], fields: [] }`; never mutate `schema`.

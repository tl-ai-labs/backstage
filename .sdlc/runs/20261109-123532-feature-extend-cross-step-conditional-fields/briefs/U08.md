### U01 — edit `plugins/scaffolder-react/src/next/lib/schema.ts` (codegen)

Behaviour: Adds two internal helpers: one lists the property names a step schema declares inside conditional branches, the other tells the step's cross-step conditions (reading a property the step does not declare) apart from same-step ones.

Rules:
1. 1. `getConditionalPropertyNames(schema)` walks from `schema` into: each object item of `allOf`, `anyOf` and `oneOf` arrays; the `then` and `else` objects; and each object value of the `dependencies` object (array values are skipped); it recurses into the reached subschemas through those same keywords only.
2. 2. For every reached subschema (never the top-level `schema` itself) whose `properties` is an object, collect its own keys (use `hasOwnProperty`, like `extractUiSchema`).
3. 3. Never walk into `if`, `not`, `items` or any `properties` value; ignore non-object nodes.
4. 4. Return the names in first-seen order without duplicates as `string[]`; never mutate `schema`.
5. 5. Reuse the file's existing `isObject` guard; add a short `//` comment above each new function saying what it is used for; no TSDoc release tag and do not touch next/lib/index.ts.
6. 6. `getCrossStepConditions(schema)` uses an inner test `declaredHere(name)`: true when `name` is an own key of `schema.properties`, or when `getConditionalPropertyNames` of `{ ...schema, dependencies: <schema.dependencies without name> }` includes `name` (use `schema` as is when `schema.dependencies` is not an object).
7. 7. It inspects only two kinds of condition: (a) `if` nodes, meaning `schema` itself and each object item of `schema.allOf` whose `if` is an object; the condition reads the own keys of `if.properties` plus the string items of `if.required`, and its branches are `then` and `else` (objects only); (b) each own key `k` of `schema.dependencies` whose value is an object; the condition reads `k`, and its branch is that value. Array-valued dependencies and any other nesting are ignored.
8. 8. A condition is cross-step when at least one name it reads fails `declaredHere`; those names go into `keys`. The names a branch declares are the own keys of its `properties` plus `getConditionalPropertyNames(branch)`.
9. 9. `fields` = names declared by the branches of cross-step conditions, minus the names declared by the branches of same-step conditions, minus `keys`, minus the own keys of `schema.properties`.
10. 10. Return `{ keys, fields }`, each in first-seen order without duplicates; a schema with only same-step conditions (or none) returns `{ keys: [], fields: [] }`; never mutate `schema`.

Exports:
- `function getConditionalPropertyNames(schema: JsonObject): string[]`
- `function getCrossStepConditions(schema: JsonObject): { keys: string[]; fields: string[] }`

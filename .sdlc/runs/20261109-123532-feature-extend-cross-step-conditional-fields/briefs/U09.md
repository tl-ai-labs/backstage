Behaviour: Adds `expandCrossStepDependencies`, which rewrites `dependencies` keyed on an answer from another step into equivalent `allOf` if/then entries that rjsf evaluates against the full form data.

Rules:
1. 1. If `schema.dependencies` or `schema.properties` is not an object (use `isObject`), return `schema` itself (same reference).
2. 2. Visit the own keys `k` of `schema.dependencies` in `Object.keys` order; skip `k` when it is an own key of `schema.properties` (same-step dependency, rjsf already handles it).
3. 3. Also skip `k` when `getConditionalPropertyNames({ ...schema, dependencies: <schema.dependencies without k> })` includes `k` (a field introduced by another branch of the same step, which rjsf resolves through its dependency chain).
4. 4. For an array value `v`: produce `{ if: { required: [k] }, then: { required: v } }`.
5. 5. For an object value: split it into `oneOf` and the remaining keywords `rest`; when `rest` has at least one key produce `{ if: { required: [k] }, then: rest }`; when `oneOf` is an array, for each item that is an object whose `properties` is an object holding an object at `properties[k]`, produce `{ if: { properties: { [k]: item.properties[k] }, required: [k] }, then: { ...item, properties: <item.properties without k> } }`; skip other items.
6. 6. Any other value produces nothing.
7. 7. If nothing was produced return `schema` itself; otherwise return `{ ...schema, allOf: [...(Array.isArray(schema.allOf) ? schema.allOf : []), ...produced] }`, keeping `dependencies` unchanged so ajv validation still matches the backend.
8. 8. Never mutate `schema` or its nested objects; build the copies with spread and Object.fromEntries/filter.
9. 9. Add a short `//` comment above the function explaining that rjsf skips a dependency whose key is not a property of the step, so cross-step dependencies are re-expressed as if/then.

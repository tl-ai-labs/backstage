### U01 — create `plugins/scaffolder-react/src/next/lib/conditionalSchema.ts` (codegen)

Behaviour: Pure helpers that resolve a wizard step's JSON Schema against the accumulated answers of all steps, so a condition in step N can reference an answer from an earlier step, and that report which answers have become unreachable.

Rules:
1. Declare a module-local `function isObject(value: unknown): value is JsonObject` exactly as lib/schema.ts does. Do not import one.
2. Declare a module-local `const validator = customizeValidator();` at module scope, from '@rjsf/validator-ajv8'. Build it once per module, never per call.
3. Import `retrieveSchema` from '@rjsf/utils'. It is exported from that package's root.
4. `collectGoverningKeys(stepSchema)`: return the set of property names a step's conditions test. Collect every key of `stepSchema.dependencies` when it is an object. When `stepSchema.if` is an object, collect every key of `if.properties` when that is an object, and every string entry of `if.required` when that is an array. Recurse into `then`, `else`, and each object entry of `allOf`, `anyOf`, `oneOf`, and into each object value of `dependencies`, collecting their `dependencies` keys and `if` keys the same way. Never collect a plain `properties` key as governing.
5. `collectConditionalPropertyNames(stepSchema)`: return the set of property names declared ONLY inside conditional subschemas. Walk `dependencies` values, `if`, `then`, `else`, and each object entry of `allOf`, `anyOf`, `oneOf`, recursively; at every node BELOW the root collect the keys of that node's `properties` when it is an object. Never collect the keys of the root's own `properties`.
6. `pickConditionData(stepSchema, formState)`: return a new plain object holding, for each key of `collectGoverningKeys(stepSchema)`, that key's value from `formState` when `formState` has it as an own property. Omit any key `formState` lacks. Never include a key that is not governing.
7. `resolveStepSchema(stepSchema, formState)` returns the SAME `stepSchema` reference, with no copying, when any of: `stepSchema` is not an object; it has no object `dependencies` and no object `if`; it has no own object `properties` key (RJSF already resolves a dependencies-only step correctly, so leave it alone); or every governing key is already a key of its own `properties`.
8. Otherwise `resolveStepSchema` computes, for each governing dependency key NOT in its own `properties`, an isolated probe `{ type: 'object', properties: { [key]: {} }, dependencies: { [key]: stepSchema.dependencies[key] } }`, calls `retrieveSchema(validator, probe, probe, formState)`, and takes from the outcome every `properties` entry except the probe's own stub key, plus every `required` entry except that stub key.
9. When `stepSchema.if` is an object and at least one of its governing keys is absent from the step's own `properties`, resolve it with one further probe `{ type: 'object', properties: <a stub {} per absent governing key>, if: stepSchema.if, then: stepSchema.then, else: stepSchema.else }`, include `then`/`else` only when each is present, and take from the outcome every property and required entry except the stub keys.
10. The returned schema is a shallow copy of `stepSchema` with: `properties` set to the step's own properties followed by the collected additions (an addition never overwrites an own property of the same name); `required` set to the step's own `required` entries followed by the collected additions, de-duplicated, and the `required` key deleted entirely when that list is empty; each consumed cross-step dependency key removed from `dependencies`, and the `dependencies` key deleted when nothing is left in it; and `if`, `then`, `else` deleted when the `if` probe ran. Never mutate `stepSchema` or anything reachable from it.
11. `pruneUnreachableFormState(stepSchemas, formState)` returns the SAME `formState` reference whenever it would drop nothing, including when no step declares a conditional property.
12. A key is dropped by `pruneUnreachableFormState` only when all of: it is in the union of `collectConditionalPropertyNames` over every step; it is NOT a top-level `properties` key of ANY step (a key any step declares at top level is a real answer and always survives); it is absent from the `properties` of EVERY step's `resolveStepSchema(step, formState)` under the current state; and `formState` has it as an own property. Dropping otherwise is a defect.
13. When at least one key is dropped, return a new shallow copy of `formState` without those keys. Never delete a key from the argument.
14. No helper throws for any input. A governing key answered in no step yields no additions and no drops. A malformed subschema (a string, null, an array where an object is expected) is skipped, not an error.
15. No helper logs, and none deep-clones a whole step schema or the manifest.

Exports:

- `function pruneUnreachableFormState(stepSchemas: JsonObject[], formState: Record<string, JsonValue>): Record<string, JsonValue>`
- `function pickConditionData(stepSchema: JsonObject, formState: Partial<{ [key: string]: JsonValue }>): Partial<{ [key: string]: JsonValue }>`

Import line: `import { resolveStepSchema, pruneUnreachableFormState, pickConditionData } from '../../lib/conditionalSchema';`

Style from: `plugins/scaffolder-react/src/next/lib/schema.ts` — The house shape for a pure JSON Schema walker in this package: module-local isObject type guard, named export function, recursion over properties/items/anyOf/oneOf/allOf/dependencies/then/else, TSDoc with an @alpha tag on each export.

Covers: FR-2, FR-3, FR-4, NFR-3, NFR-4, NFR-5, NFR-6

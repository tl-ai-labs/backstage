Behaviour: Adds liftCrossStepDependencies, which rewrites a step's top-level dependencies keyed on a field the step does not declare into allOf if/then entries that rjsf and ajv resolve against the whole form state.

Rules:

1. 1. Signature `export const liftCrossStepDependencies = (schema: JsonObject): JsonObject => { ... }`, an arrow-function const like extractSchemaFromStep, with a short TSDoc comment (no release tag: it is not exported from the lib barrel).
2. 2. If `schema.properties` or `schema.dependencies` is not an object (use the file's existing `isObject` helper), return `schema` itself (same reference).
3. 3. Walk `Object.entries(schema.dependencies)` in order. Keep an entry in a new `remaining` object when its key is an own key of `schema.properties`, or when its value is neither an array nor an object (boolean dependencies stay as they are). Every other entry is lifted.
4. 4. If no entry was lifted, return `schema` itself (same reference), so steps whose dependencies all name their own properties keep a byte-identical schema.
5. 5. An array value D for key K lifts to `{ if: { required: [K] }, then: { required: D } }`.
6. 6. An object value without an array `oneOf` lifts to `{ if: { required: [K] }, then: value }` with value unchanged.
7. 7. An object value with an array `oneOf`: split it into `{ oneOf, ...rest }`; keep only the `oneOf` entries that are objects whose `properties` is an object with own key K; map each kept branch to `{ if: { properties: { [K]: branch.properties[K] }, required: [K] }, then: { ...branch, properties: <branch.properties without K> } }`; the lifted entry is `{ if: { required: [K] }, then: { ...rest, allOf: [...(rest.allOf if it is an array, else []), ...mappedBranches] } }`.
8. 8. Return `{ ...schema, allOf: [...(schema.allOf if it is an array, else []), ...liftedEntries] }` with `dependencies` set to `remaining`, or with the `dependencies` key left out entirely when `remaining` has no keys.
9. 9. Never mutate `schema`, its `properties`, its `dependencies` or any branch: build new objects and arrays only.
10. 10. Put any inner helper (for example one that lifts a single entry) above the export as a plain `function`, matching extractUiSchema's style; add no new import (JsonObject and isObject are already in the file).
